先用一分钟了解我们在做什么

我们关注如何从分辨率受限的 MRI 中恢复可信的结构，近期重点是心脏 Cine：既要看清每一帧，也要保留真实的心脏运动。方法上探索高斯表示、时序信息和 Flow Matching；评价上同时检查空间误差、时间误差、数据来源和推理输入。

目前最重要的三件事：

  1. GaussM2ASR 原方法的完整预算训练正在进行。 在本地 IXI 子集上，第一阶段 40,000 步已完成；第二阶段 25,320/500,000 步，最近第 24,000 步的 ×4 验证为 27.781 dB / SSIM 0.88930。完整实验尚未完成，尚不能判定达到论文效果。
  2. 心脏适配已得到有效的空间基线。 ACDC 独立 20 位测试患者上，单帧微调为 26.144 dB / 0.78112，比 Fourier 输入提高 1.648 dB。多帧引导和已尝试的时序约束还没有稳定、实用的额外收益。
  3. 旧结果需要看数据来源。 一批旧 cardiac_mvp 数据存在轴转换和真值问题，相关结论已经作废；当前 ACDC 结果来自重新核验的数据。较早的 FM、Loop、FlowGS 项目保留为工程与研究参考。

工作全景与方法

核心问题

心脏 Cine 是随时间变化的 MRI 图像序列。我们希望改善低分辨率输入的结构清晰度，同时避免帧间闪烁、虚构纹理和把真实运动抹平。当前得到验证的是合成退化条件下的空间重建改善；真实采集和临床用途仍需额外证据。

为什么近期转向 GaussM2ASR

作者提供了可运行的网络和 CUDA 渲染器，像素/频域重建目标也较明确，适合建立医学重建基线和逐项消融。相比同时改 codec、生成器和时序模块，先核验一个完整的公开方法更容易定位问题。

原方法输入为 LR 目标对比 + 已配准的 HR 参考对比，例如低分辨率 T2 与高分辨率 T1。网络融合两路特征，预测高斯中心、形状和强度，再在连续坐标上渲染图像。各向异性表示高斯在不同方向可以有不同宽度，有助于表达细长边界。

公开方法包含特征融合、参考引导调制、空间/频域注意力、Gaussian Transformer，以及 Anatomy-Guided Gaussian Parametrizer（AGGP）。原始网络约 1,749 万参数。两阶段训练先学习高斯表示，再冻结 AGGP，训练不同倍率的重建。

从脑 MRI 到心脏时，改了什么

心脏部署场景没有保证存在同一时相、已配准的 HR 参考模态，因此目前心脏方案让引导只来自 LR 中心帧或 LR 邻帧。HR 只作为训练监督和评测真值。这改变了输入协议，是心脏任务适配实验。

已比较单帧、未对齐多帧、运动对齐多帧、对齐加时序损失，并追加两种子和更强约束验证。当前结果支持微调本身有效，尚不支持这些时序改动形成方法优势。

Flow Matching 在这里是什么

FM 学习一个向量场，把初始潜变量沿连续路径推到目标潜变量，再由 decoder 生成图像。推理需要解常微分方程，计算量取决于向量场调用次数 NFE。潜空间 codec 的表达上限、条件输入和积分误差都会影响最终结果。

注意两种“流”：motion_flow 是相邻帧的运动位移；fm_time 是生成路径上的时间参数。它们不是一个物理量。Loop 的 K 是共享网络循环次数，也不能直接等同于 NFE。

评价模型的角色

评价 MVP 用 RankNet 学习已知退化之间的相对排序，输出无参考质量分。它可以辅助工程质控，但对伪结构、病变或诊断质量是否可靠，仍需独立标注与验证。早期小样本分数不作为当前心脏重建成果的主证据。

IXI 原方法最容易看错的地方

  • 数据类名含 Bicubic，但实际公开默认实现做 Fourier 低通，裁频后零填回原尺寸，模型收到的 LR 和参考具有相同像素网格。
  • 发布代码对每张 LR 做 uint8 min-max 处理；它与心脏 LR-only 浮点归一化协议不同。
  • 论文文字对频域损失的幅值谱描述，与代码的复数 FFT 差 L1 存在差异；本轮按公开代码执行，并记录这一差异。
  • Stage 1 是 ×1 的表示学习；Stage 2 才训练 1–4 倍率的超分，且整个 AGGP 冻结。高 ×1 PSNR 不代表高倍率恢复质量。
  • 当前本地划分为 96/12/12 人，SimpleITK 仿射配准。论文中的数据量和 FSL-FLIRT 流程不同。

当前 ACDC 协议

ACDC 官方 training 100 按五类诊断分层，固定 60/20/20 位患者。训练 561 条切片序列，验证和测试各固定 3 个切片/患者。保持原生时间帧，不做时间插值，也不把序列首尾当真实相邻帧。

先中心方形裁剪、抗混叠缩放到 128×128，再保留对称 31×31 个 Fourier 系数并零填回 128 网格，称为名义 ×4。归一化仅从观察到的 LR 序列计算，不能使用 HR 最大值。所有方法使用相同的数据一致性处理。

指标使用未裁剪、未量化的浮点输出，data_range=1，单位由上述 LR 归一化定义。ED/ES 分割标签仅用于解剖区域误差统计，不参加推理。这是幅度图合成超分辨率，不等同于真实多线圈复数 k-space 重建。

旧数据为什么不能继续使用

旧 cardiac_mvp 转换器误把 [time, slice, coil, PE, RO] 解释成另一轴序，时间、切片和线圈被混淆。修正轴后，又确认该批原始数据缺少相位编码线，零填充 RSS 图存在折叠，不能作为 HR 真值。

受影响的旧 cardiac_mvp 医学结果已经作废。 对应缓存保留用于审计，当前转换器会拒绝把已识别的欠采样数据导出成 HR。独立 IXI 与 AID RGB 不受影响。较早 FM/Loop 项目的具体数据来源应逐项追溯，不能自动把所有项目都判为有效或无效。

新数据开始前应明确：实际轴序、FFT 中心与维度、采样掩膜、线圈组合、是否真全采样，以及部署时真正可用的输入。仅文件名写着 full、HR 或 cine 不足以保证这些条件。

指标怎么读

指标意义常见误读
PSNR ↑与参考图的像素误差，dBdB 是对数单位，不能用“本地 PSNR/论文 PSNR”作为性能百分比
SSIM ↑局部结构相似度不等于诊断结构已恢复
LPIPS ↓特征空间感知距离自然图像特征对医学影像不天然有效
FID ↓生成与参考分布的特征距离小样本估计波动大，低 LPIPS 不保证低 FID
相邻帧误差 ↓预测帧差与真值帧差的 MAE直接压小帧差可能只是在抹平真实运动
解剖区域图像误差 ↓分割标签区域内的重建误差不能称为分割器性能或心功能测量改善

按患者划分，再逐帧计算、逐患者等权汇总，避免帧数多的患者占更高权重。置信区间按患者配对重采样；两个训练种子仍是同一批 20 位测试患者，不能算成 40 位。

上游 STADNet 的历史要求是 Python 3.6 / PyTorch 1.4，与当前环境不同；照其旧 README 全局降级会破坏现有工作。新环境应单独创建，先完成 CPU 检查，再验证 CUDA 扩展兼容性。

问题与后续方向

当前最值得先解决什么

先把基线证据补齐。 正在运行的 IXI 完整预算实验应保留配置和数据版本、完成各倍率独立测试，并与本地相同退化和输入条件的基线比较。若分数仍有差距，应优先拆解预处理、配准、数据规模、指标与公开实现差异。

仅补足步数不保证达到论文原表。反过来，本地中期分数偏低也不足以判定原文不可靠。把“方法能执行”“本地协议有效”“论文同条件可复现”分别写清楚。

为什么时序收益可能很小

已尝试的多帧/时序方法收益接近零，可能涉及邻帧信息增量有限、LR 运动估计不足、已有数据一致性压缩改动空间，或损失与真正运动不匹配。已有验证诊断的整图平均光流幅度约 0.053 像素；背景会拉低均值，不能据此认定心脏没有运动。

下一步宜先在心脏前景、不同运动幅度和不同时间间隔上做诊断，并查看对齐残差和置信度。仅继续增大时序损失权重，已有实验未显示实用收益。

值得讨论的改进假设

假设最小验证方式成功后再做
有效邻帧信息未被利用固定模型，分运动幅度/前景统计多帧相对单帧的验证增益设计自适应邻帧选择和可靠性加权
高斯缺少稳定身份对应检查相邻帧中心、协方差与真实运动的关系用运动运输中心与协方差，加小残差
感知伪纹理由 codec 带来检查 HR→codec→HR 上限与频谱修 codec 后再比较 FM 与 shortcut
方法只在合成退化有效获取并核验真实测量、采样与线圈信息真实复数 k-space 数据一致性与重建对照

这些是后续假设，尚未实现为被验证的成果。运动运输协方差可考虑 Σ_t = J_t Σ_0 J_tᵀ，但运动误差和形状生理变化必须单独检查。

延续实验的决策原则

先保持输入和预算一致，每次只增加一个主要变量；先在 VAL 达到预设的实用门槛，再做独立确认。当前心脏续训使用过的门槛是：PSNR 至少 +0.05 dB 且相邻帧误差至多增加 1%，或 PSNR 至多下降 0.02 dB 且相邻帧误差至少下降 5%。它是本组该轮实验的工作标准，并非公认临床阈值。

若继续 FM，宜先稳定确定性重建，再把 FM 用于受约束的残差或潜变量。对每一条新路线同时报告质量、真实端到端耗时和失败案例；感知分数改善不能替代医学保真证据。
