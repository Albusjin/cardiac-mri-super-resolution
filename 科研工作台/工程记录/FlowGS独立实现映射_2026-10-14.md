## 上一轮历史映射

本实现固定参考 arXiv:2605.22147v1，使用 RGB AID 图像。目标是验证两阶段生成与连续倍率渲染能否工作，并提供小预算实测证据；没有官方代码逐层对齐的依据。

| 原文 | 实现位置 | 本轮选择及限制 |
|---|---|---|
| 式 (1)：HR 与 LR↑ 拼接，H/8 细节潜变量 | `model.py::LDMEncoder/FlowGSCodec.encode_target` | 六通道输入；四个残差层级、三次下采样；宽度 32、倍率 [1,2,2,4]、潜通道 4；高斯后验；采用 LDM 风格结构，不宣称与原作者逐层相同。非 8 整除目标尺寸使用 ceil(H/8)。 |
| 式 (2)：独立 CondNet | `flow.py::ConditionalFlow.encode_condition` | 独立权重的缩窄编码器，只接收 LR↑；EMA 同时更新 CondNet 和速度网络。 |
| 式 (3)–(4)：直线路径 FM | `flow.py::flow_loss` | 标准高斯噪声与后验样本线性插值，回归 z1−z0；MSE 对全部元素取平均。不额外标准化潜变量。 |
| 式 (5)–(7)：1/4 shortcut | `flow.py::flow_loss` | 每批恰有 2/8 样本做 SC；EMA 教师两次短步、学生一步，教师停止梯度。原文未给出 Δt 的具体采样；自主选择半步 {1/2,1/4,1/8,1/16} 及可行 dyadic 起点；时间、步长分别嵌入。纯 FM 持续使用零步长条件。 |
| 式 (8)–(9)：Euler 与一步推理 | `flow.py::sample_latent`、`inference.py::FlowGSPipeline` | NFE=1/2/4/8；同图同噪声，固定种子；正式 API 只接收 LR、输出尺寸与采样参数。 |
| 式 (10)：尺度感知特征融合 | `model.py::FeatureFusion` | 独立编写四阶段残差融合，使用 log2(实际 y/x 倍率) 调制，目标网格为 Hout×Wout。没有照搬 LDCSR 原多阶段 decoder，是主要结构差异。 |
| 式 (11)–(13)：Gaussian bank 和 softmax 混合 | `model.py::GaussianField.bank/parameters_at` | K=100；Cholesky 参数保证 SPD，先混合协方差和 opacity，再计算 PDF。初始化、坐标单位和参数化为自主选择。 |
| 式 (14)–(15)：高斯聚合 | `model.py::GaussianField.forward/query` | 7×7 邻域，包含 PDF 归一化常数与 opacity，不除以邻域权重和；目标像素单位，越界邻居贡献为零；支持非整数坐标查询。局部截断不等于全域高斯和。 |
| 式 (16)–(17)：轻量残差与 bicubic 跳连 | `model.py::FlowGSCodec.decode` | 两个 1×1 卷积和 SiLU；末层零初始化；Torch bicubic、align_corners=False；输出评价统一裁剪/取整到 uint8。 |
| 式 (18)：重建+LPIPS+GAN+KL | `scripts/run_pilot.py::train_codec` | λ1=1、λ2=.5、λ3=1e−6；LPIPS-Alex；hinge PatchGAN 从 500 步开始；LDM 梯度比例自适应权重上限自主设为 1。KL 按图求和再按批均值。 |

## 数据和训练预算

全部 10,000 张镜像 HR 已逐张验证 SHA256、解码及 600×600 RGB。候选原划分为 LDCSR 的 8000/1000/1000，尚无证据表明 FlowGS 沿用。按类别与固定哈希排名，在各自候选组内选择 TRAIN900、VAL150、TEST150。验证选择名单与尺度测试名单各 30 张，每类一张；不同阶段共用划分。

训练仅取 96×96 随机块，名义倍率均匀采样 [1,8]；LR 由 Pillow uint8 BICUBIC、floor(H/s) 生成，使用翻转与 90° 旋转。验证为中心 128×128；正式 TEST 为中心 192×192。输入 RGB /255，不做逐图标准化。实际倍率由目标与 LR 尺寸计算。×10 仅用于冻结后的范围外测试。

| 参数 | 原文 | 独立初步实验 |
|---|---|---|
| codec 预算 | 1,000,000 iterations | 2,000 steps，batch4 |
| codec 学习率 | 4.5e−6 | 1e−4，Adam |
| FM 预算 | 400 epochs | 各 3,000 steps，batch8，FM+SC 与 pure FM 各一组 |
| FM 学习率、预热 | 1e−5、1000 steps | 1e−4、200 steps，AdamW、weight_decay=0 |
| EMA | .999 | .999，条件和速度一起更新 |
| 网络和解码器 | LDM/LDCSR 相关结构 | 缩窄的独立实现，上表明确结构选择 |

codec 以固定 30 VAL 的 mean(L1+LPIPS) 选择，用后验均值；FM 各自以相同 VAL、相同噪声的一步 EMA LPIPS 选择。TEST 不用于选权重、倍率、NFE、种子或训练预算。FM 两组具有相同初始状态、数据次序与冻结 codec，记录哈希；SC 会使用额外教师计算，因此相同步数不代表相同 FLOPs 或壁钟预算。只做一个训练种子，无法估计训练间方差。

SC 步长采样是未获确认的实现选择：FM 只监督 d=0，最小非零教师半步为 1/16，没有针对该半步的显式 FM 锚定；非零步长依赖共享网络与自一致学习。原文没有给出该边界规则。应在 VAL 上核查这一点，不能仅凭本轮负结果否定原方法。

## 评价与解释边界

LPIPS 使用 lpips 0.1.4 的 AlexNet v0.1、normalize=True。FID 使用 pytorch-fid 0.3.0 的官方 Inception 2048，每张图的一个完整中心裁剪为一个样本；不将 patch 当作额外图像，不降低特征维度。通过样本因子交叉矩阵 SVD 计算完整协方差 FID，与标准协方差公式核对过。150/30 张的样本量与裁剪均不同于原文，不能直接对比原表 FID 或 LPIPS。

PSNR 按每图 RGB 值计算后取均值；SSIM 为 11×11、σ=1.5 的 valid Gaussian RGB 窗口，无 shave。所有方法和 HR 均以相同 RGB uint8 PNG 像素评价。bicubic 基线与模型残差底图完全相同。LPIPS 差值采用按类别内图像配对的 10,000 次 bootstrap，仅描述本组图像上的不确定性，不反映训练随机性或跨数据集泛化。

`oracle_hr` 使用真实 HR 后验均值，是 codec 诊断，不能部署；`zero_latent` 只置零 decoder 输入，是诊断，不能称为论文 w/o Flow 消融。`plain_nfe1` 与 FM+SC 使用相同 codec，但分别训练，是本轮实际的 shortcut 对照。尚未单独训练原文无 Flow 网络，尚未做 DOTA/DIOR 或医学实验。

512×512 计时固定 batch1、同一 GPU、5 次预热和 20 次重复；包括 LR H2D、条件编码、Euler、特征融合、高斯聚合、裁剪取整及 SR D2H，用 CUDA synchronize 对齐。排除权重加载、指标计算和 PNG IO。FP32 启用 TF32；固定随机种子与 cuDNN deterministic 不保证不同软件/硬件环境下的整轮 bitwise 一致。
