# LIIF 心脏 Cine MRI 验证方案与项目推进计划

## 一、验证目标与总体安排

**先用 LIIF 建立可信的确定性基线，再判断高斯表示、Flow Matching（FM）和一步生成是否值得继续投入。**

按已确认的选择，分两阶段开展：

1. **对齐现有名义 ×4 协议**：回答 LIIF 在相同数据和输入条件下，能否提供稳定、有效、成本可控的心脏重建。
2. **独立验证连续倍率**：回答同一个模型是否能处理不同分辨率和非整数倍率，而不仅是接口能输出不同尺寸。

依据[初筛文档](../基线选型/开发与对比基线初筛_2026-10-28.md)与[项目评价口径](../../03_数据与评价口径.md)设计。本轮交付限于方案，不连接服务器、不编写训练代码、不启动训练。

需要检验的假设如下：

| 假设 | 验证目的 | 能支持的结论 |
|---|---|---|
| LIIF 能从 LR 单帧恢复有效空间信息 | 建立简单、可审计的比较起点 | 是否适合作为确定性对比基线 |
| LIIF 在统一预算下接近已有心脏适配模型 | 判断复杂模型是否具有实际优势 | 是否值得作为开发主干或工程退路 |
| 一个模型能处理多个倍率 | 检验连续表示在 MRI 中的有效性 | 已测倍率范围内的任意尺度能力 |
| 空间改善没有明显损害结构和时间变化 | 防止只改善整图平均分数 | 合成协议下的结构与时序表现 |

LIIF 本身是确定性连续表示模型；它的前馈输出不能称为“FM 的 NFE=1”。其连续坐标、局部集成和 cell decoding 设计来自[原始论文](https://arxiv.org/html/2012.09161v2)。

## 二、冻结数据、模型和两套任务协议

### 1. 数据与输入条件

- 沿用现有 ACDC **60/20/20 位患者隔离划分**及诊断分层，不重新随机划分。
- 正式训练使用既有 TRAIN 切片序列；VAL 沿用每患者固定三个切片和原生时间帧。
- 推理只使用 LR 图像，以及从 LR 得到的归一化统计、坐标和输出尺寸请求。
- 沿用已审计的 LR 序列归一化。训练真值使用同一组 LR 统计变换，禁止使用 HR 最大值重新归一化。
- ED/ES 标签只用于评价，不用于模型输入、训练采样或检查点选择。
- 本轮开发只看 TRAIN/VAL。历史 TEST 已经使用，最终只能称为“冻结配置后的历史测试集确认”。

服务器准备阶段必须核验患者清单、数据版本、归一化和数据一致性处理。**本地资料没有完整给出其实现细节，因此应以服务器已有审计版本为准，不能临时猜测替代。**

### 2. 模型及接口

采用官方固定版本 `4c833f8f9d5d038df3ee2b50ebe649c30e628c0f` 的 EDSR-baseline LIIF：

- EDSR 编码器：16 个残差块、64 通道，关闭内部上采样。
- 输入和输出均改为单通道，主实验从随机初始化训练。
- 保留局部集成、特征展开和 cell decoding。
- MLP 使用四层 256 隐藏单元。
- 首轮只用 L1 重建损失，不加入 GAN、感知损失、FM 或时序模块。

沿用概念接口：**LR 图像 + 查询坐标 + cell → 灰度预测值**；HR 仅进入训练损失或评价模块。输出尺寸来自固定实验请求，不从 HR 图像内容获取。

上述基础配置对应[官方训练配置](https://raw.githubusercontent.com/yinboc/liif/4c833f8f9d5d038df3ee2b50ebe649c30e628c0f/configs/train-div2k/train_edsr-baseline-liif.yaml)。MRI 适配必须替换原有图像读取、退化和评价入口，保持浮点数据，避免 PIL/uint8 转换。

### 3. 两套协议分别训练、分别排名

| 项目 | A：历史协议对齐 | B：连续倍率验证 |
|---|---|---|
| 主要问题 | 在现有任务中是否有效 | 一个模型能否处理多个倍率 |
| 输入 | 128×128 低通幅度图 | 小网格 LR 幅度图 |
| 输出 | 128×128 | 固定目标网格 128×128 |
| 退化 | 保留既有对称 31×31 Fourier 系数，零填回原网格 | Fourier 低通后直接重建到相应小网格 |
| 倍率含义 | 名义带宽 ×4，输入输出网格比为 1 | 同时记录名义退化倍率与实际网格倍率 |
| 对照 | Fourier 输入、现有 LR-only 心脏单帧适配模型 | 小网格 LR 的 bicubic 插值、同协议固定 ×4 LIIF |
| 能否与历史结果直接比较 | 同条件重新评价后可以 | 不可以 |

**A 阶段中，LIIF 的 cell 和输出网格固定，因此该实验只能证明同网格重建能力，不能证明任意倍率能力。**

B 阶段采用以下统一定义：

- 训练名义倍率从 \(U[1,4]\) 采样；每个训练批次使用相同倍率，避免尺寸填充影响。
- 小网格边长取 \(n=\lfloor128/s+0.5\rfloor\)。
- 除 ×1 恒等观测外，保留可装入该网格的最大奇数宽度、中心对称频率集合；按统一像素中心坐标在 \(n×n\) 网格重建后取幅度。
- 固定 FFT 归一化，保证常量图像退化前后强度一致；记录频率支持、网格大小、像素中心和实际倍率 \(128/n\)。
- 测试名义倍率：**1.5、2、2.5、3、3.5、4**；**5、6**单列为训练范围外探索。
- 主表采用无额外数据一致性后处理的输出，不直接套用 A 阶段的处理。

该设置验证的是**幅度图合成超分**，不能外推为真实多线圈 MRI 重建。

## 三、服务器分阶段验证流程

默认单卡 48GB、同一时间一个训练任务。建议首轮总预算上限 **144 GPU 小时**，这是资源上限，不是预计耗时；每阶段通过后才放行下一阶段。

| 阶段 | 具体工作 | 通过条件 | 预算上限 |
|---|---|---|---:|
| P0：协议审计 | 核验环境、数据划分、观测生成、归一化、评价及旧权重版本 | 无患者交叉；旧输入基线能按原口径重现 | 主要为 CPU |
| P1：工程验证 | 无 HR 推理、非整数尺寸、梯度、显存、分块查询和恢复检查 | 输出正确、梯度有限、无明显数值差异 | 2 GPUh |
| P2：学习验证 | 少量 TRAIN 患者拟合，独立小 VAL 检查 | 能拟合训练样本，验证效果出现合理改善 | 4 GPUh |
| P3：A 正式验证 | 60 TRAIN/20 VAL，两个种子 | 获得稳定曲线、患者级指标和成本报告 | 48 GPUh |
| P4：B 连续倍率 | 混合倍率两个种子；固定 ×4 一个种子作控制 | 多倍率接口与质量分别通过 | 72 GPUh |
| P5：统一评价 | 重评现有对照、计时、患者级统计和失败案例 | 得出基线选型结论 | 18 GPUh |

### P1：先证明实现可信

必须覆盖以下检查：

- **无 HR 推理**：移除真值后，仍可独立构造输入、坐标和 cell。
- **尺寸检查**：例如 32×32 LR 分别输出 80×80、104×104 和 128×128；这里只验证接口。
- **坐标检查**：用常量、脉冲和棋盘图排查轴交换、中心偏移、镜像及强度缩放错误。
- **完整训练步检查**：包含前向、损失、反向和优化器更新，而非只测推理显存。
- **查询分块检查**：编码一次后分块查询；与整图查询相比，FP32 最大绝对差目标不超过 \(10^{-5}\)。
- **恢复检查**：检查点保存模型、优化器、学习率、随机数状态及采样进度，恢复后训练连续。

默认 FP32；先测 batch 1，再依次测试 2、4。选择训练峰值不超过显存约 80% 的最大 batch，通过梯度累积保持**有效 batch=4**。

### P2：区分“能学习”和“能泛化”

从 TRAIN 中固定选择覆盖五类诊断的 5 位患者；小 VAL 从既有 VAL 中独立选择 5 位患者，不按结果挑人。

先用少量固定帧做拟合，再使用这 5 位 TRAIN 患者做短程训练：

- 固定帧训练 L1 相对初始值至少下降 50%，作为排错门槛。
- 查看训练样本是否恢复合理轮廓，排除仅输出均值或平滑图像。
- 小 VAL 同时看 PSNR、SSIM、前景误差和失败图。

训练拟合通过但小 VAL 尚未超过输入时，先检查过拟合和预算，不立即淘汰模型；**小样本结果只用于排错和发现明显失败，不能用于宣布最终胜负。**

### P3/P4：统一正式训练设置

以下为本项目建议配置，不宣称复现 LIIF 原论文预算：

| 项目 | 默认设置 |
|---|---|
| 随机种子 | 16、17 |
| 训练输入 | 完整视野，不照搬自然图像 LR patch48 |
| 每帧监督 | 随机抽取 2304 个目标坐标 |
| 数据采样 | 患者均匀，再抽切片和时间帧 |
| 优化器 | Adam，初始学习率 \(10^{-4}\) |
| 学习率调整 | 20k、40k 更新时各乘 0.5 |
| 单次训练上限 | 60k 次优化器更新或 24 GPUh，先到者停止 |
| 验证频率 | 每 2k 次更新，完整 VAL 整图评价 |
| 检查点选择 | A 按患者等权 PSNR；B 按六个训练范围内倍率等权平均 PSNR |
| 数据增强 | 首轮关闭，减少协议变量 |
| 保存 | 最优、最近、少量里程碑检查点 |

达到 20k 更新后，若连续五次验证的最佳选择指标提升不足 0.02 dB，可按预设规则早停。若达到时间上限仍明显上升，标为“预算内尚未收敛”，不能写成模型无效。

B 的混合倍率模型和固定 ×4 控制模型均重新初始化，避免把 A 阶段训练成本隐含带入比较。两个种子分别保留结果，不按种子挑选最佳成绩。

服务器按需读取数据，先用 2 个数据加载进程；不采用全数据内存缓存，不为每个倍率复制整套数据。运行前检查服务器 RAM、显存及磁盘，结束后保留最终成果并清理可再生临时文件。

## 四、评价、判定标准与预期结果

### 1. 评价内容

| 维度 | 指标或检查 | 目的 |
|---|---|---|
| 整图重建 | PSNR、SSIM | 与项目既有口径一致 |
| 解剖区域 | ED/ES 心肌、左右心室区域 MAE；标签边界邻域误差 | 检查背景是否掩盖局部退化 |
| 时间变化 | 相邻帧差分相对 HR 差分的 MAE | 检查逐帧重建是否引入闪烁或抹平运动 |
| 失败分布 | 患者配对差值、最差患者、按诊断分组结果 | 避免只看平均值 |
| 工程成本 | 参数量、训练峰值显存、GPUh、端到端延迟 | 判断后续开发成本 |

采用未裁剪、未量化浮点输出，`data_range=1`；不沿用自然图像的 Y 通道评价或额外裁边。

逐帧计算后，先在患者内部汇总，再患者等权平均。主要比较报告患者配对 bootstrap 95% 区间；两个种子的患者区间分别计算，不能把同一批患者重复计数。

A 阶段同时报告：

- 原始模型输出；
- 所有方法经过相同、已审计数据一致性处理后的输出。

正式性能比较以统一后处理结果为主，原始结果用于判断收益来源。

计时统一设备、精度和 batch1，预热 20 次后测量 100 次，报告中位数及 P95。包含编码、查询、数据搬运和必要后处理；另报整条 Cine 的耗时。

### 2. 预先登记的工作门槛

以下是**项目工程判据，不是公认临床阈值**。

| 判定 | 建议标准 | 后续动作 |
|---|---|---|
| 可用确定性基线 | A 相对 Fourier 输入，两个种子患者平均 PSNR 均提升至少 0.5 dB，SSIM 不下降；无系统性前景恶化 | 保留为正式对比方法 |
| 有竞争力的开发候选 | 与同条件重评的现有单帧适配模型相比，PSNR 差距不超过 0.1 dB，SSIM及结构检查相近 | 综合成本决定主干 |
| 连续倍率验证通过 | B 在六个训练范围内倍率上均优于 bicubic 的患者平均 PSNR，且无系统性 SSIM/前景退化 | 可支持已测范围内连续倍率有效性 |
| 明显失败 | 多次排错后仍不能拟合，或正式预算内持续弱于输入且无改善趋势 | 暂停后续扩展，记录失败原因 |
| 证据不足 | 小增益、种子方向不一致、区间跨零或尚未收敛 | 保留结论边界，不宣布胜出 |

“LIIF 是合格比较基线”和“LIIF 应成为开发主干”是两个独立判断。即使它略弱于现有模型，清楚、稳定的确定性参照仍然有价值。

### 3. 预期结果应如何表述

合理预期是：LIIF 可以提供较容易审计的 LR-only 参照，并帮助确认现有复杂模型的收益是否值得其成本。**目前不能提前给出可信的最终 PSNR，也不能保证超过已有模型。**

三类结果均有明确价值：

- **LIIF 表现接近或更好**：优先选择较简洁的开发起点。
- **LIIF 明显较弱，高斯方法稳定更好**：支持继续研究高斯表示，但仍需受控比较才能归因。
- **LIIF 只改善整图指标，边界或时序变差**：说明当前损失或评价不足，应先处理保真问题。

最终交付应包含协议卡、配置与版本索引、训练曲线、逐患者结果、固定展示案例、最差案例、成本表，以及“继续/调整/停止”的决策记录。

## 五、推进整个项目的后续计划

以下按单卡顺序推进，以验收条件决定进入下一阶段。周次仅供排期，实际取决于服务器可用时间及实测速度。

| 阶段 | 主要工作 | 进入下一阶段的条件 |
|---|---|---|
| 第1周：协议与 LIIF 起点 | 完成审计、工程检查、小样本学习和 A 首个种子 | 输入、评价和训练行为可信 |
| 第2—3周：LIIF 基线完成 | 完成 A 重复、B 连续倍率及控制实验 | 明确 LIIF 的能力、局限和成本 |
| 第3—4周：选定开发主干 | GSASR Paper/EDSR 版先做算子、灰度、显存验证，再与 LIIF 同协议比较 | 存在可重复的质量或成本优势 |
| 第5—6周：受控 FM 验证 | 在选定确定性基线上学习 LR 条件残差流；先检查表示上限，再比较多步结果 | FM 对结构保真或质量具有明确增益 |
| 第7—8周：一步化 | 比较同一 FM 模型的 1/4/8/16 次调用，再验证专门的一步训练或蒸馏 | NFE=1 满足质量与端到端速度要求 |
| 后续：多帧与独立确认 | 单帧冻结后增加邻帧；最后在配置冻结后做测试和外部确认 | 新模块通过预设门槛，结论可复现 |

具体推进原则如下：

1. **先决定高斯是否值得。**  
   GSASR 与 LIIF 尽量使用相近 EDSR 容量、相同输入、损失和采样条件，同时报告更新步数与 GPUh。若高斯没有质量或成本优势，不强制将其加入最终方法。

2. **FM 先解决一个明确问题。**  
   默认研究确定性重建后的残差：条件来自 LR，目标残差来自训练 HR 与确定性预测之差。先与参数量相近的确定性残差网络比较，排除“只是网络更大”的解释。RFMSR 可用于借鉴训练配方，但不直接把重型自然图像先验作为默认 MRI 主干。

3. **多步有效后，再投入一步化。**  
   对同一模型测量 NFE 与质量的关系，区分积分步数不足和训练目标不足。一步化暂用 PSNR 损失不超过 0.1 dB、SSIM 损失不超过 0.003、前景误差增加不超过 2% 作为相对多步参照的工作门槛，并要求端到端耗时实际下降。

4. **多帧阶段一次增加一个变量。**  
   先比较中心帧与三帧条件，再考虑对齐或时序损失；不同时改变表示、FM 和运动模块。可沿用项目既有门槛：PSNR 至少增加 0.05 dB 且时序误差增加不超过 1%，或 PSNR 下降不超过 0.02 dB 且时序误差至少降低 5%。

5. **最后形成可核验的研究主张。**  
   优先完成“单帧 LR-only、已测连续倍率、FM、NFE=1”的证据链；高斯和多帧依据结果决定保留。真实采集泛化、分割和心功能改善另行验证，不从合成图像分数直接推导。

最终成功标准是：在明确的 LR-only 心脏 Cine 协议下，证明哪些模块带来了可重复的质量或速度收益，并据此选定开发路线。
