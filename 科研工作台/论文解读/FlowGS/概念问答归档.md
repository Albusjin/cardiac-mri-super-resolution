这句话的意思是：**INR 方法把“放大后的像素值是多少”变成一个可以按坐标随时询问神经网络的问题。** 因此，同一个模型可以根据需要生成不同尺寸的图像。

比如，你有一张低分辨率 MRI，想放大：

- 放大 **2 倍**时，需要生成一组较稀疏的输出像素坐标。
- 放大 **3.5 倍**时，需要生成另一组更密的坐标。
- INR 模型针对每个坐标，结合原图中附近的特征，预测这个位置的像素值；把这些预测值排起来，就是放大后的图像。

可以把它想成一个函数：

$$
\text{像素值} = f(\text{查询坐标},\ \text{原图附近的特征})
$$

这里有三个关键词：

- **隐式神经表示（INR）**：用神经网络学习“位置与图像内容之间的关系”，而不是只保存一张固定尺寸的像素图。
- **连续坐标**：查询位置不局限于原图已有的像素点，可以是它们之间的位置。
- **解码**：把坐标和图像特征转换成该位置的预测像素值。

所以，“基于连续坐标的解码成为主流范式”，就是说：**很多任意倍率超分辨率方法，都采用了“给定坐标 → 预测像素值”这一思路。** 这里的“主流”是论文作者对已有研究的概括。

还要注意，**坐标可以任意查询，不代表模型知道原图中缺失的真实细节**。输出值仍然是根据低分辨率输入和训练中学到的规律预测出来的。

在 FlowGS 论文的上下文里，作者接着指出：这些方法虽然能连续查询坐标，但底层特征往往仍存储在离散网格上，需要插值；作者认为这可能影响空间连续性。随后论文介绍 GaussianSR 用高斯场表示局部信息。依据见[中英对照稿第 1 页 S003–S004](paper.md)。

你问得很准：**“高斯泼溅由 FM 驱动”容易让人以为 FM 在直接控制高斯核怎么移动或泼溅，但这篇论文不是这么做的。** 更准确地说，FM 先生成细节信息，再把它交给后面的高斯渲染模块使用。

可以把流程拆成三步：

```text
低分辨率图像 ───────────────┐
                            ├→ 特征融合 → 高斯渲染 → 高分辨率图像
噪声 + 低分辨率图像 → FM → 细节潜变量 ┘
                              ↑
                         还要输入目标倍率
```

1. **FM 负责生成细节信息。** 低分辨率图像中的很多高频细节已经缺失，比如细小纹理和边缘。FlowGS 以低分辨率图像为条件，通过 FM 把噪声变成一个**细节潜变量**。它可以理解为一份压缩的“可能需要补充的细节信息”，还不是最终图片。

2. **融合模块把信息接起来。** 它将 FM 生成的细节潜变量、低分辨率图像的结构特征，以及目标放大倍率结合起来，形成一个尺度感知特征场。

3. **高斯泼溅负责连续表示与渲染。** 后续模块利用这个特征场预测高斯相关参数，并在目标坐标上聚合高斯特征，生成超分辨率结果。目标倍率变了，就可以在相应的坐标位置进行查询和渲染。

所以，作者说的“FM 驱动”，可以理解为：**FM 为高斯渲染提供生成出来的细节先验，从而影响最终重建结果。** 论文中 FM 也不是唯一输入：原始低分辨率图像和目标倍率同样参与后续重建。

再换个生活中的比喻：假设要把一张模糊地图放大，**FM 先根据模糊地图生成一份可能的细节草稿；高斯模块再结合原地图、这份草稿和所需尺寸，把结果绘制出来。** 这个比喻是帮助理解，并不表示网络真的先画出一张完整草稿。

两者各自解决的问题也不同：

| 模块 | 在这篇论文中的作用 |
|---|---|
| **FM** | 学习并生成缺失高频细节的潜在表示 |
| **高斯泼溅** | 构造连续特征表示，支持不同倍率下的渲染 |
| **两者结合** | 让生成的细节参与任意倍率重建 |

对应论文证据是[第 2 页 S011–S012](paper.md)和[第 3 页 S026–S029、公式（10）](paper.md)。图 2 也展示了这个连接方式。

是的，**LDCSR 也是一种超分辨率模型**。这张图在比较 FlowGS 和其他模型的生成效果、运行时间及参数量。

纵坐标 **FID** 是一种衡量生成图像与真实图像在整体分布上有多接近的指标。一般来说，**FID 越低越好**：图中越靠下，表示生成结果与真实图像的整体分布越接近。

不过，FID 衡量的是**一批图像的整体分布**，不能单独说明某一张图重建得准不准，更不能只凭它判断 MRI 中的病灶或解剖结构是否真实。

图中另外两个信息也值得一起看：

- **横坐标 Runtime (ms)**：推断时间，单位是毫秒，越靠左通常越快。注意中间有一个断轴，2,800 后跳到了 13,200，不能按整条轴均匀估算。
- **圆圈大小 Parameters (M)**：模型参数量，M 表示百万。圆越大，参数越多；参数量本身并不等于运行速度。

**LDCSR** 全称是 *Latent Diffusion for Continuous-Scale Super-Resolution*，也是用于遥感图像**连续倍率超分辨率**的模型。它和 FlowGS 的目标相近，但主要生成方式不同：

| | LDCSR | FlowGS |
|---|---|---|
| 细节生成 | 潜空间扩散，需要多步生成 | 流匹配，论文默认使用单步生成 |
| 任意倍率重建 | 连续倍率上采样模块 | 连续倍率高斯渲染 |
| 图中定位 | 浅粉色小圆，FID 约 23 | 黄色圆，FID 约 22 |

按照图中的实验，FlowGS 的 FID 略低、推断时间也略短；但它的圆更大，表示**参数量更多**。这些比较是在论文指定条件下得到的：FID 使用 DIOR 数据集的 **4 倍超分辨率**结果，时间使用单张 NVIDIA RTX 4090 对 **512×512 图像**测量。[论文图 1](https://arxiv.org/html/2605.22147v1)；[LDCSR 项目](https://github.com/MoooJianG/LDCSR)。
