# 可复用记录模板

使用时按研究问题创建独立 Markdown 文件；未完成字段写“未确认”，不要编造内容。模板不代表已开展实验。

## 检索日志

- 检索日期与时区：
- 研究问题与纳入/排除条件：
- 使用的数据库或搜索工具：
- 实际查询词、过滤条件与查看范围：
- 已查看/去重/保留数量（仅填实际可核对数量）：
- 无法访问的来源与检索限制：
- 下一轮补查内容：

## 文献卡

- 文献 ID、标题、作者、年份、版本、DOI/arXiv ID、原文链接：
- 阅读程度：元数据 / 摘要 / 全文 / 补充材料 / 代码；分别标注。
- 官方代码及确认作者关联的证据、读取时的版本：
- 任务、输入信息、数据集、划分、退化与归一化：
- 单帧/多帧、固定/连续倍率、训练/测试倍率：
- FM 的源状态、目标状态、条件、训练目标和采样方法：
- NFE、完整推理耗时、硬件与测量条件：
- 核心结果及表格/章节/代码位置：
- 局限、与你们任务的差异、缺失信息：
- 用途：开发候选 / 公平对比候选 / 技术参考 / 排除及原因。

## 基线候选比较

| 候选 | 输入是否匹配 | 倍率能力 | 代码/权重 | 资源需求 | 需适配内容 | 已验证到哪一步 | 选择理由 |
|---|---|---|---|---|---|---|---|

不同论文原表数字不得直接作为统一排名；优先记录是否可在同一协议下重测。

## 实验卡

- 实验 ID、日期、负责人、状态：拟议 / 就绪 / 运行 / 完成 / 失败。
- 问题与可证伪假设：
- 假设成立/不成立各预期观察到什么：
- 基线与唯一主要变量；混杂因素控制：
- 数据版本、患者划分、退化、倍率与推理可用输入：
- 代码提交、环境、配置、初始化权重：
- 训练步数、种子、GPU/显存/存储预算、停止条件：
- 主指标、辅助指标、患者聚合与不确定性估计：
- 预先约定的通过门槛与选模规则：
- 实际命令、日志、检查点与图表位置：
- 测试集访问历史和方案冻结时间：
- 实际结果、失败案例、支持/不支持的结论：
- 后续决定及原因：

## 周报

- 本周目标与完成事项：
- 新证据及来源：
- 失败实验与学到什么：
- 未决问题和阻塞：
- 下周最多三项任务、负责人、交付物与依赖：
- 需要负责人提供的信息或作出的决定：
