## 已有证据与研究边界

- 10 月 17 日 ACDC 合成协议下，GaussM2ASR 的 LR-only 单帧心脏适配改善空间指标；时序尝试未达到该轮门槛。
- LIIF、GSASR、RFMSR 是优先验证候选，角色不同；尚无本项目同协议实验证明其胜负。
- 历史“×4”是 Fourier 低通后零填回同一网格，不等于直接把图像边长放大四倍。
- 历史 TEST 已使用；新方法先在 TRAIN/VAL 开发，不能将其重新称为未接触盲测。
- 本仓库没有训练框架、医学原始数据、模型权重及完整服务器训练源码。现有配置是参考快照，不能直接当可执行训练入口。
