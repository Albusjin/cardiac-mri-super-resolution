# 云端与跨设备使用

说明核对日期：2026-10-29。仓库：<https://github.com/Albusjin/cardiac-mri-super-resolution>。

## 直接在云端继续

在另一台电脑登录同一 ChatGPT/Codex 账号，选择 **Work in → Cloud → Select environment**；新建环境时选择本 GitHub 仓库，检查环境准备结果并 Publish，再开始任务。仓库未出现时，检查 GitHub 连接是否可访问它。界面与权限以账号实际显示为准。[官方 Codex Cloud 说明](https://learn.chatgpt.com/docs/cloud)

此仓库的文档与校验只需 Python 标准库；环境准备时明确无需 PyTorch、CUDA 或数据下载。环境配置入口可在 **Settings → Codex Cloud → Environments** 找到。[官方环境说明](https://learn.chatgpt.com/docs/environments/cloud-environments)

进入任务后粘贴 [HANDOFF 的续接指令](../HANDOFF.md)。先让云端读取项目文件，再开始论文讨论、方案整理、轻量检查或后续代码准备。

实际云端环境尚未在本轮创建或验证。GPU 训练、实验室服务器网络、私有数据和本机连接不会因上传 GitHub 自动配置。

## 也可以在笔记本本地工作

有 Git 时：

```bash
git clone https://github.com/Albusjin/cardiac-mri-super-resolution.git
cd cardiac-mri-super-resolution
python3 tools/verify_repository.py
```

不想安装工具时，直接在 GitHub 阅读 Markdown，或通过 **Code → Download ZIP** 下载后打开 `index.html` 及课程 HTML。仓库中的根目录 `index.html` 仍是 10 月 17 日新人包入口，最新信息以 README、HANDOFF 和项目状态为准。

## 每次工作前后

```bash
git pull --ff-only
```

修改资料后检查差异，更新清单并提交：

```bash
python3 tools/verify_repository.py --write
python3 tools/verify_repository.py
git status --short
git diff
git add <本次确认要提交的文件>
git commit -m "更新研究方案与项目状态"
git push
```

写入 GitHub 仍需登录及仓库写权限。首次克隆只是读取文件，不会自动导入原电脑聊天记录、账号凭据或插件；需要的研究上下文已归档在本仓库。第三方技能按需配置，不要整体复制原电脑的全局配置与密钥。
